All study sources now point to newly researched external upstream projects and the corresponding new personal forks. Older personal project references have been removed from this archive.

## Using a note

Pick one small exercise, record the actual date you start, create a reproducible fixture, and retain the result alongside the proposed evaluation. Report limitations and unsuccessful attempts. Research questions remain questions until evidence supports an answer.

## Attribution

Upstream software and assets keep their original licenses and credits. This repository links to them and does not relicense their contents. Forks are identified as upstream study sources, not original implementations.
