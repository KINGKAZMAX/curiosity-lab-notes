## Why this project is in the collection

The highest-star reviewed browser-3D engine directly fits new browser-based spatial and virtual-exhibition exercises.

This is a study fork of [mrdoob/three.js](https://github.com/mrdoob/three.js). The upstream authors retain credit for the software. The purpose of this note is to connect an existing tool to a small, inspectable exercise in this personal research practice.

## First adaptation exercise

Keep the first iteration local and small. Use synthetic examples or assets with documented reuse permission. Record the specific upstream release or commit before implementation, then isolate personal experiments from upstream source so future synchronization remains reviewable.
