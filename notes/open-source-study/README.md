# Open-source study

Retrospective study material compiled on 2026-10-27. Historical Git author dates are editorial archive slots chosen for this collection, not evidence that the notes, experiments, forks, or software existed or were completed on those dates. Git committer dates retain the actual time of compilation. Referenced projects and APIs may postdate an archive slot. All proposed exercises remain unexecuted unless a later dated record supplies results. No participant data or research findings are claimed.

- [Study plan: affaan-m/ECC](affaan-m--ecc.md) — Review one upstream research-first development workflow and draft a minimal local adaptation plan for a public HCI notebook, without installing or executing its agents, hooks, or skills.
- [Study plan: NousResearch/hermes-agent](nousresearch--hermes-agent.md) — Design a consent and memory-boundary study for a fictional personal agent using static dialogues and a fake tool layer.
- [Study plan: n8n-io/n8n](n8n-io--n8n.md) — Specify a manual-trigger workflow that reads three local bibliographic fixtures, normalizes their fields, and writes a review queue without sending messages or contacting external services.
- [Study plan: firecrawl/firecrawl](firecrawl--firecrawl.md) — Plan a source-ingestion exercise using three self-authored local HTML fixtures, preserving title, canonical URL, headings, and source provenance in a normalized record.
- [Study plan: microsoft/markitdown](microsoft--markitdown.md) — Design a conversion audit for a self-authored DOCX, a small slide deck, and a plain-text exhibition label, comparing retained headings, tables, and attribution.
- [Study plan: ollama/ollama](ollama--ollama.md) — Draft an offline-first avatar conversation harness with a fake model adapter first, a visible model identifier, and explicit controls for clearing session memory.
- [Study plan: huggingface/transformers](huggingface--transformers.md) — Plan a small benchmark protocol for classifying synthetic visitor intents in a digital museum; begin with a keyword baseline and reserve model evaluation for a later implementation.
- [Study plan: Comfy-Org/ComfyUI](comfy-org--comfyui.md) — Draft a reproducible visual-storyboard workflow manifest for a fictional cultural exhibit, recording prompt text, seed, model provenance, and human selection decisions.
- [Study plan: excalidraw/excalidraw](excalidraw--excalidraw.md) — Plan a participatory-design canvas with zones for participant claims, supporting evidence, unresolved questions, and design decisions.
- [Study plan: godotengine/godot](godotengine--godot.md) — Specify a tiny exhibition-exploration game with one room, three inspectable objects, keyboard controls, and a deterministic save-state schema.
- [Study plan: mrdoob/three.js](mrdoob--three-js.md) — Plan a browser exhibition room with three placeholder objects, selectable labels, a camera reset, and a plain HTML object list.
- [Study plan: d3/d3](d3--d3.md) — Specify a cultural-exhibit timeline over a synthetic event dataset with linked filters, an accessible table, and visible uncertainty intervals.
- [Study plan: mermaid-js/mermaid](mermaid-js--mermaid.md) — Draft three diagrams for a human-AI co-creation study: data lineage, consent-state transitions, and review-to-publication flow.
- [Study plan: pmndrs/react-three-fiber](pmndrs--react-three-fiber.md) — Plan a reusable exhibit-card scene component whose selected object, HTML details, and URL state remain synchronized.
- [Study plan: GraphiteEditor/Graphite](graphiteeditor--graphite.md) — Draft a procedural poster exercise for a fictional exhibition, with an inspectable node graph, an editable palette, and three parameterized layout variations.
- [Study plan: processing/p5.js](processing--p5-js.md) — Specify an interactive cultural-pattern sketch using original geometric motifs, three adjustable parameters, and a reproducible seed.
