# Computational space

Retrospective study material compiled on 2026-10-27. Historical Git author dates are editorial archive slots chosen for this collection, not evidence that the notes, experiments, forks, or software existed or were completed on those dates. Git committer dates retain the actual time of compilation. Referenced projects and APIs may postdate an archive slot. All proposed exercises remain unexecuted unless a later dated record supplies results. No participant data or research findings are claimed.

- [Make massing constraints inspectable](parametric-massing-constraints.md) — A new design exercise for explaining hypothetical geometry constraints before comparing generated urban forms. The linked project supplies context, not evidence that this workflow is implemented.
- [Compare urban options without hiding disagreement](participatory-urban-comparison.md) — A proposed comparison session that preserves individual priorities and makes the basis of urban design choices visible. No participant study or preference outcome is claimed.
- [Use landmarks to test spatial wayfinding](spatial-interface-wayfinding.md) — A new navigation exercise inspired by public spatial projects. Proposed routes, controls, and observations are a study plan rather than descriptions of existing repository features.
- [Keep globe clusters geographically honest](globe-marker-aggregation.md) — A proposed marker aggregation exercise using the public globe project as context. It specifies synthetic fixtures and inspection criteria without asserting an existing clustering implementation.
- [Turn a 3D performance budget into a testable contract](three-dimensional-performance-budget.md) — A new engineering exercise for balancing rendering cost and useful interaction. The proposed budgets are provisional test targets, not measured results or guarantees for the referenced projects.
- [Guide the camera while preserving user control](camera-guidance-with-user-control.md) — A proposed camera behavior study for explaining spatial content without disorienting the viewer. It describes a new interaction experiment rather than completed interface behavior.
- [Provide a complete path around the map](accessible-map-alternatives.md) — A new content and interaction exercise for making location information usable through a structured list. It proposes practical checks without claiming accessibility certification.
- [Package a procedural result so it can be regenerated](reproducible-procedural-generation.md) — A new reproducibility exercise for procedural spatial studies. It separates deterministic generation checks from judgments about design quality and makes no claim of completed replication.
- [Separate offshore scene context from operational claims](offshore-information-layers.md) — A new information design exercise using a public offshore simulation fork as visual context. Proposed statuses and tasks use synthetic data and are not operational or safety guidance.
- [Make scale and coordinate conventions travel with the model](scale-and-unit-handoff.md) — A new model handoff exercise that uses explicit units, reference geometry, and transformation records. It proposes validation fixtures rather than reporting interoperability results.
