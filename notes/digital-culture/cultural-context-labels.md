# Write context labels that expose uncertainty and scope

A new labeling exercise for separating documented context from contemporary interpretation. It proposes a field structure and review process rather than asserting facts about particular cultural objects.

## Question

Which contextual details help a visitor understand an object without reducing a living cultural practice to a fixed category? This exercise considers origin, period, use, terminology, and the source of each description. It asks how a label can remain concise while showing uncertainty and variation. The task is not to supply missing facts from general knowledge, but to make the scope of the available documentation clear and avoid presenting one recorded account as universally applicable.
