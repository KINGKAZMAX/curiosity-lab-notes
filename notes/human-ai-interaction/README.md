# Human–AI interaction

Retrospective study material compiled on 2026-10-27. Historical Git author dates are editorial archive slots chosen for this collection, not evidence that the notes, experiments, forks, or software existed or were completed on those dates. Git committer dates retain the actual time of compilation. Referenced projects and APIs may postdate an archive slot. All proposed exercises remain unexecuted unless a later dated record supplies results. No participant data or research findings are claimed.

- [Consent Before Character Memory](consent-before-character-memory.md) — A prospective design exercise separating conversational context from persistent character memory, with inspection, correction, and deletion controls. Linked projects provide thematic inspiration, not implementation evidence.
- [Calibrating Trust When Evidence Is Incomplete](calibrating-trust-with-incomplete-evidence.md) — A proposed interface study of appropriate reliance on AI suggestions using fictional planning tasks and deliberately varied evidence quality. References motivate the topic only.
- [Decision Records for AI Co-Creation](decision-records-for-ai-cocreation.md) — A new design plan for documenting alternatives, human selections, and unresolved tradeoffs during an AI assisted spatial concept exercise.
- [Visible Human Override in Robot Controls](visible-human-override-in-robot-controls.md) — A simulation only design exercise for clear command ownership, cancellation, and recovery in a robot control interface. The linked repository is a forked reference, not claimed original work.
- [Uncertainty in Rehabilitation Prototype Feedback](uncertainty-in-rehabilitation-prototype-feedback.md) — A nonclinical interface exercise for distinguishing observation quality, simulated signals, and unsupported interpretations in a movement related demonstration.
- [Interruptible Voice Turns Without Losing Intent](interruptible-voice-turns.md) — A prospective voice interaction experiment separating stopping playback, replacing a request, and preserving a draft response in a fictional character conversation.
- [Accessible Task Paths in AI Interfaces](accessible-task-paths-in-ai-interfaces.md) — A design exercise making a small AI assisted task complete through keyboard, readable text, and multiple input routes, without assuming a particular user capability.
- [Explicit Boundaries in AI Character Relationships](boundaries-in-ai-character-relationships.md) — A proposed interaction study of clear fictional roles, optional reminders, and easy exits in character experiences, with user agency as the design focus.
- [Explanations That Support Checking](explanations-that-support-checking.md) — A new interface plan for concise, verifiable explanations of AI assisted recommendations using explicit observations and assumptions rather than unverifiable accounts of internal reasoning.
- [Evidence Logs for Interaction Experiments](evidence-logs-for-interaction-experiments.md) — A practical documentation plan for separating observations, proposals, synthetic examples, and retrospective notes in small interaction experiments and future research records.
