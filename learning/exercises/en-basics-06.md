# 叙述一个虚构的昨天

## 目标

用少量常见动词练习一般过去时，并理解 did not 后面使用动词原形。虚构故事仅用于练习，不作为个人历史记录。

## 步骤

1. 先读原创短故事，找出 yesterday 与过去发生的动作之间的关系。
2. 把一个全新虚构人物昨天做的两件事写在纸上，再写一件没有做的事。
3. 本轮可以使用 visited、read 和 wrote；不知道的变化要单独查清，不把所有动词都机械加 ed。
4. 将否定句中的动作词与肯定句比较，确认 did not 后面的词形，并在稿旁注明故事是虚构练习。

## 原创示例

Yesterday, Lin visited a small museum.
Lin wrote a short note.
Lin did not buy a postcard.

## 你来完成

为虚构人物 Mei 写四句昨天的故事：两句肯定、一个使用 Did 的问句，以及一个使用 did not 的否定句。使用 visit、write、buy 中至少两个动词。

## 自查

- [ ] 故事中的过去动作使用了合适的过去式。
- [ ] Did 或 did not 后面的实义动词使用原形。
- [ ] 我将内容标为虚构故事，没有把它写成自己真实完成过的学习活动。
