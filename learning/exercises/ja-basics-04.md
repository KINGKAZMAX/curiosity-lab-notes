# 用の表达所属关系

## 目标

区分主题助词 は 与连接所属关系的 の，用一个小物品场景说明是谁的东西，建立最基本的名词连接方式。

## 步骤

1. 先读原创例句，分别找出表示主题的 は 和连接两个人或物名词的 の。
2. 为任务中的两个虚构人物各分配一件物品，用中文确认所属关系之后再写日语。
3. 将同一个句子中的所属人替换一次，观察主要需要改动哪一部分。
4. 写完后用中文回译检查，确认没有把谁的东西写反；不会的物品词可以先查入门材料。

## 原创示例

これはわたしのノートです。
これはリンのペンです。

## 你来完成

虚构情境：アン 的物品是 本，リン 的物品是 ノート。分别用 これは……の……です 写两句；再用 わたし 替换其中一位所属人。

## 自查

- [ ] の 位于所属人和物品之间，顺序没有写反。
- [ ] 句子仍然包含主题部分和完整的 です 结尾。
- [ ] 我能用中文准确说明每件物品属于谁。
