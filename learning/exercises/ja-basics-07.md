# 用を连接动作与对象

[返回练习目录](README.md) · [语言路线](../languages/README.md)

状态：待练习。编制日期：2026-10-27。历史作者日期仅是回溯归档位置，不表示已在该日完成学习。例句与任务为本次原创；官方链接供进一步学习，不表示例句摘自官方材料。

## 目标

用三个常用动作练习对象加 を 的简单句，理解读什么、喝什么、写什么之间的对应关系。

## 步骤

1. 阅读原创例句，圈出动作对象，划出 を 后面的动词，先在中文中确认句意。
2. 按照任务中的三组词写句子，不需要添加自己还不会的复杂修饰。
3. 写完后朗读，核对 を 作为助词时的读音，并观察它与前面的名词是怎样连接的。
4. 再选择一件新物品替换原来的对象，但要检查替换后与动作是否搭配合理。

## 原创示例

本を読みます。
水を飲みます。
名前を書きます。

## 你来完成

用 本／読みます、水／飲みます、名前／書きます 各组成一句。然后将其中一组的对象替换为你查明词义的新词，再写一条新句子。

## 自查

- [ ] 动作对象和动词之间都有 を。
- [ ] 新替换的对象与动作搭配合理，我能解释其含义。
- [ ] 我已核对 を 的助词读音，而不是按中文逐字念。
