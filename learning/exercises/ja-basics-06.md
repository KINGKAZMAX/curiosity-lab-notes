# 名词句的肯定与否定

[返回练习目录](README.md) · [语言路线](../languages/README.md)

状态：待练习。编制日期：2026-10-27。历史作者日期仅是回溯归档位置，不表示已在该日完成学习。例句与任务为本次原创；官方链接供进一步学习，不表示例句摘自官方材料。

## 目标

在简单物品判断中练习 です 与 ではありません，理解完整否定表达，不把中文的不是逐词搬进日语。

## 步骤

1. 阅读原创例句，比较肯定和否定结尾，先确认否定的是哪一个判断。
2. 用任务给定的真实设定作答：这里的真实仅指虚构练习内部的设定，不代表现实中的物品。
3. 先写否定句，再写一句正确的肯定说明，确保两句说的是同一个对象。
4. 把长一点的否定结尾分段读几次，然后遮住例句重写，检查是否漏字。

## 原创示例

これは本です。
これはペンではありません。
これはノートです。

## 你来完成

虚构设定：桌上物品是 ノート，不是 本；另一个物品是 ペン，不是 ノート。每个物品分别写一肯定句和一否定句。

## 自查

- [ ] 肯定句采用 です，否定句采用完整的 ではありません。
- [ ] 四句与给定的两组物品设定相符。
- [ ] 我能说明每句是在肯定还是在否定什么。
