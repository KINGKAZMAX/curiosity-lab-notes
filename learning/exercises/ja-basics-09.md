# 说明物品和动物在哪里

[返回练习目录](README.md) · [语言路线](../languages/README.md)

状态：待练习。编制日期：2026-10-27。历史作者日期仅是回溯归档位置，不表示已在该日完成学习。例句与任务为本次原创；官方链接供进一步学习，不表示例句摘自官方材料。

## 目标

在一个简单虚构房间里练习位置说明，初步区分本题中物品使用的 あります 与动物使用的 います。

## 步骤

1. 阅读原创例句，找出对象、位置和句尾表达，并先画一张很简单的房间示意图。
2. 只使用任务给出的物品、动物和位置，先确认中文意思，再写日语句子。
3. 比较两句结尾为何不同，暂时限定在本题的书和猫，不把初学规则扩大到所有特殊情况。
4. 完成后把文字与自己画的示意图逐项对照，查看是否遗漏位置中的 の 或 に。

## 原创示例

本は机の上にあります。
ねこはへやにいます。

## 你来完成

虚构设定：书在桌子上，猫在房间里。写出对应的两句说明；再把书的位置改为 いすの上，写一条新的物品位置句。

## 自查

- [ ] 本题的书使用 あります，猫使用 います。
- [ ] 位置表达与 に 的连接完整，机の上 和 いすの上 没有漏掉 の。
- [ ] 三个句子与房间示意图一致，我能用中文复述。
