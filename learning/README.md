# 专属学习与改造入口

从基础英语、日语和一个小型工程练习开始，把资料、任务、原始输出和真实验证连接起来。当前目标为 IELTS 7.5 与 JLPT N2，考试日期未定。十二周仅用于基础重建，不预设达标时间。

计划建立：2026-10-27。本页列出的是待执行路线；学习分数、实际用时和结果由真实执行记录补充。

## 今天怎么开始

1. 打开[语言学习路线](languages/README.md)，完成一小段英语起点任务与日语假名检查，保留原始答案。
2. 从工程或研究方向只选一个任务，先用原创虚构场景做小文件或规格说明。
3. 使用[学习记录模板](templates/learning-record.md)记录实际过程；周末填写[每周回顾](templates/weekly-review.md)。

## 每周节奏

英语 45 分钟、日语 35 分钟，每周六天；另留 80 分钟做一个小改造，40 分钟复盘，合计约十小时。保留间隔与休息，时间不足时缩小任务。

[查看逐周安排与进入下一阶段的条件](12-week-plan.md)。基础英语与雅思是同一条逐步进阶的主线，不另外叠加一套每天必须完成的考试课程。
