# 英语、雅思与日语学习路线

这份计划依据你提供的起点：英语、日语都需要重新打基础；长期目标为 IELTS 7.5 与 JLPT N2，目前没有考试日期。下面的十二周是基础重建阶段，不表示十二周内达到这两个考试目标。按申博用途暂以 IELTS Academic 为默认，报名之前仍需核对目标院校、项目与签证要求的考试类型、总分和单项分数。

## 每周十小时，先形成可持续节奏

| 任务 | 安排 | 周投入 |
|---|---|---:|
| 英语主线 | 每天 45 分钟，每周六天 | 270 分钟 |
| 日语主线 | 每天 35 分钟，每周六天 | 210 分钟 |
| 一个语言工具小改造 | 每周一次，只做一个可验收任务 | 80 分钟 |
| 周复盘 | 检查错误、证据与下周任务 | 40 分钟 |
| 合计 | 保留一天的语言休息空间，可灵活调整 | 600 分钟 |

英语 45 分钟可分为：10 分钟复习自己做的卡片、15 分钟有理解检查的听读、15 分钟写作或录音、5 分钟修正一个反复出现的错误。日语 35 分钟可分为：10 分钟假名或词汇、15 分钟句型与短文、10 分钟听音模仿和一句自己的表达。复习积压时先减少新卡，不用添加空提交补偿错过的学习日。

## 前两周：建立基线，不用分数给自己贴标签

| 日期范围 | 英语 | 日语 | 必须留下的证据 |
|---|---|---|---|
| 第 1–3 天 | 做英国文化协会免费等级测试，保存日期与结果；录一段 60–90 秒的自我介绍；写 80–120 词介绍一个新建的虚构小展览练习 | 测试平假名、片假名的认读与听辨；用最熟悉的表达录 30 秒自我介绍，允许只说几句 | 原始答案、录音、未修改初稿、困难清单；所有分数为空直到实际完成 |
| 第 4–7 天 | 选择容易理解的短音频与 A1/A2 材料，先独立理解再看文本；标记听不出、看不懂、表达不出三种问题 | 从 Irodori Starter 选入门单元；检查发音、基本语序、助词和简单问答 | 一篇短摘要、一组自编句子、一张可复查的错误表 |
| 第 8–10 天 | 用另一份相近难度材料验证弱项；不重复同一套题制造进步 | 用另一组假名和同难度短句复查；熟悉 JLPT N5 官方题型即可 | 两次可比较但不同材料的记录 |
| 第 11–14 天 | 选出最重要的两个基础问题，例如时态与听音分词；将自己的句子做成少量卡片 | 选出两个基础问题，例如片假名与助词；将短句改写成自己的场景 | 每门语言的基线页、下一阶段任务、来源链接和实际学习日期 |

英国文化协会测试提供的是粗略水平指示，重点测语法、词汇和表达理解，目前访问测试需要登录；不能当作 IELTS 成绩，也不能替代听说写的基线记录。[官方测试](https://learnenglish.britishcouncil.org/english-levels/online-english-level-test)

## 十二周基础重建

| 周次 | 英语重点 | 日语重点 | 新练习产出 |
|---|---|---|---|
| 1–2 | 基线、常用句型、听读习惯 | 假名、基本语序与问答 | 双语学习基线页；两段真实录音 |
| 3–4 | 主谓一致、常用时态、基本连接词；短段落表达 | 假名薄弱项、常见助词、肯定否定与问句 | 用简单英语写一段全新虚构 HCI 原型介绍；用日语写四句日常记录 |
| 5–6 | 描述人物、过程与比较；听取关键词 | 常用动词变化、时间地点表达、短对话 | 英语讲解一个界面流程；日语说明一天的学习顺序 |
| 7–8 | 段落中心句、原因与例子、改写；短音频复述 | 阅读短文、连接句子、听后回答 | 英语写一段设计选择及理由；日语读一则简单展品说明并写理解摘要 |
| 9–10 | 较长材料的结构、图表基本语言；自查重复错误 | 增加短文与听力长度，复习高频语法 | 用自编数据写简单图表描述；完成带来源的日语阅读记录 |
| 11–12 | 用新材料复测，整理下一阶段薄弱项；认识 IELTS 四科任务 | 用官方 N5/N4 样题了解缺口，继续口头与书面输出 | 一份前后对照的学习复盘；一个经过验证的语言工具小改造 |

上述材料难度随真实完成情况调整。官方样题用于认识题型，不把少量题目的正确率换算为正式成绩。可用 [British Council LearnEnglish](https://learnenglish.britishcouncil.org/level) 按级别选英语材料；日语以 [日本国际交流基金 Irodori](https://www.irodori.jpf.go.jp/en/) 的 Starter、Elementary 等资源为入门来源。

## 进入下一阶段的门槛

以下是这份个人计划的内部验收标准，不是 CEFR、IELTS 或 JLPT 官方定级标准。

- **英语基础门槛：**在两个不同学习日，用未做过的适配难度短文和音频，能说清主旨与几个关键细节；能写一段新建练习的说明并根据反馈修订；能不照稿讲解熟悉任务约两分钟。若主要依靠逐句翻译或背稿，继续基础阶段。
- **英语中级阶段：**逐步增加材料长度、议论结构和听力语速，再用官方 IELTS 练习建立四科基线。写作和口语应争取教师或熟悉公开评分标准的评阅者反馈；AI 批改只作辅助，不将其分数当官方成绩。
- **IELTS 7.5 专项阶段：**按目标机构的总分与单项门槛建立差距表，围绕真实最弱单项安排练习；使用不同的授权材料定期计时复测，并保留评分依据。达到稳定表现后再考虑报名，不因计划日历到了某周就默认具备目标水平。
- **日语基础门槛：**能稳定认读假名、理解并自己组成基本句子、听懂适配难度的短对话；之后依次补齐 N5/N4 基础、N3 过渡和 N2 阅读听力要求。十二周结束只决定下一阶段，不预填“已达到 N2”。
- **日语使用能力单独维护：**每周至少两次短录音和一篇简短自写文本。JLPT 不考口语与作文，其成绩不能直接证明表达能力。[官方 FAQ](https://www.jlpt.jp/e/faq/)

## IELTS 专项目录怎么使用

Academic 包含听力、阅读、写作和口语，总时长约 2 小时 45 分钟；阅读与写作各 60 分钟，口语约 11–14 分钟。[官方考试结构](https://ielts.org/take-a-test/test-types/ielts-academic-test)

写作 Task 1 至少 150 词，Task 2 至少 250 词；Task 2 在写作评分中的权重是 Task 1 的两倍。练习时分别存原稿、批注和修改稿，不只保存最后的漂亮版本。[官方写作说明](https://ielts.org/take-a-test/test-types/ielts-academic-test/ielts-academic-format-writing)

每份写作按任务完成、连贯衔接、词汇、语法四个维度写反馈；口语按流利连贯、词汇、语法、发音记录观察。这里使用公开标准做学习反馈，不复制整份评分表，也不把未评阅作品填上预测高分。[写作评分标准](https://ielts.org/cdn/ielts-guides/ielts-writing-band-descriptors.pdf)、[口语评分标准](https://ielts.org/cdn/ielts-guides/ielts-speaking-band-descriptors.pdf)

练习入口：[IELTS Academic 官方样题](https://ielts.org/take-a-test/preparation-resources/sample-test-questions/academic-test)。保存题目链接和自己的答案，公开仓库不搬运教材、付费题库、完整考试音频或未获授权的试题。

## 日语专项目录怎么使用

JLPT 从 N5 到 N1 逐级增加难度，N3 连接基础级与较高级。N2 目标需要长期阅读、词汇语法和听力积累，不能由“背完多少单词”单独判定。[官方级别说明](https://www.jlpt.jp/e/about/levelsummary.html)

使用 [JLPT 官方样题](https://www.jlpt.jp/e/samples/forlearners.html) 了解各级题型，并参照 [官方科目与时间](https://www.jlpt.jp/e/guideline/testsections.html) 做后期分项练习。日语学习中保留口语和写作练习，即使它们不在 JLPT 考试科目中。

## GitHub 与 Obsidian 的分工

| 存放位置 | 内容 | 记录方式 |
|---|---|---|
| Obsidian 私人学习页 | 原始录音、个人分数、详细错误、考试报名信息 | 写真实学习日期；链接材料和本次产出 |
| GitHub 学习仓库 | 自编练习、字段模板、工具适配文档、经过验证的小改动 | 每次提交说明具体改变与验证；保留上游来源 |
| GitHub Fork | 与上游相关的配置示例、可复现问题、测试或文档改进 | 区分个人改造、准备提交上游、已合并上游三种状态 |
| 周复盘 | 本周完成、没有完成、困难、下周一件事 | 链接实际文件或 commit；没有证据则保持待办 |

建议给每条记录固定 ID，例如 `en-2026-10-27-01`。Obsidian 记录保存 GitHub commit 链接，公开模板只保存非私密的记录 ID；不要把私人录音和成绩自动公开。历史年份索引可以回顾已有材料，但所有新练习与新改造使用真实完成日期。
